Three small things for people who run their own metal. HopOS and HOP work alone or together. SURF shows what the combination can do.

HopOS
The Go-only OS

An operating system that is only your application: no Linux, no containers, no kernel in front of the hardware. By default every app gets whole cores behind a silicon cage — on ARM and RISC-V, from a €15 board to a 128-core Ampere Altra.

~11,300 LOC · the whole OS read the HopOS story →
HOP
The orchestrator

A single binary that runs everything — processes, containers, and whole machines on HopOS. Leader, agent and API in one process; state in any S3 bucket.

~7,550 LOC · the whole orchestrator read the HOP story →
